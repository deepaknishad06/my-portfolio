# 1. Purpose

- This file is `src/components/Hero/Hero.css`.
- It exists to style the `Hero` component in your portfolio.
- It is needed because the HTML structure generated by React is raw; CSS makes it look like a polished hero section.
- It solves the problem of layout, spacing, typography, colors, animation, and responsive behavior for the hero section.
- Without it, the hero section would render with browser defaults and look unstyled and unprofessional.

# 2. File Flow

- The file begins with base styles for the hero section and its child elements.
- It defines typography, spacing, button styles, social icon styling, hero image layout, and floating badge layout.
- Then it defines animation keyframes used by the hero image and glow effects.
- Finally, it contains media queries to change the layout and size on smaller screens.
- CSS is applied in the order it appears, so earlier rules set defaults and later media query rules override them for smaller devices.

# 3. Imports

- There are no CSS imports in this file.
- The React component imports it using `import './Hero.css'`.
- If removed, the hero section would still function, but all the designed styling would disappear.
- Alternative ways:
  - Use CSS Modules (`Hero.module.css`) to scope classes automatically.
  - Use styled-components or Emotion for component-scoped styles in JavaScript.
  - Use inline styles in React, but that is harder for animations and responsive rules.

# 4. Component Structure

- This file does not define functions; it defines CSS classes.
- Each selector corresponds to an element or a group of elements in `Hero.jsx`.
- The classes are written to map cleanly to the structure of the Hero component:
  - `.hero` is the root wrapper.
  - `.hero-container` holds the two-column layout.
  - `.hero-content` is the text block.
  - `.hero-image` is the profile image area.
  - `.floating-icons` is the tech badge cluster.
- The file is written using class selectors because the React component uses `className="..."`.
- The CSS structure is intentional: general layout first, then component-specific details, then responsive overrides.

# 7. Animation

Framer Motion is not in this CSS file, but it does define CSS-driven animation:

- `animation: float 3s ease-in-out infinite;`
  - Applies to `.profile-frame`.
  - `float` is the animation name.
  - `3s` duration means one cycle takes 3 seconds.
  - `ease-in-out` makes the motion start and end smoothly.
  - `infinite` repeats forever.
- `animation: pulse 2s ease-in-out infinite;`
  - Applies to `.profile-glow`.
  - `pulse` animates opacity.
- `@keyframes float`
  - Defines the vertical movement used by `.profile-frame`.
- `@keyframes pulse`
  - Defines the glow breathing effect.

Why chosen:
- The hero image feels more alive with movement.
- The float animation gives a gentle, premium effect.
- The pulse animation emphasizes the glowing profile ring.

# 14. Common Mistakes

Beginners often make these mistakes in CSS like this:
- Using fixed widths instead of responsive units.
- Positioning elements off-screen without accounting for small viewports.
- Forgetting to hide desktop-specific elements on mobile.
- Overusing `position: absolute` when `flex` or `grid` would be better.
- Using `margin` for centering instead of `align-items` or `justify-content`.
- Not setting `box-sizing: border-box` globally.
- Not testing hover effects on mobile, where hover does not exist.
- Not using `clamp()` for fluid typography.

How to avoid them:
- Prefer `flex`/`grid` for layout.
- Test at multiple screen widths.
- Use relative units like `rem`, `vw`, and `%`.
- Keep mobile-first behavior in mind.
- Make animation optional for users who need reduced motion.

# 15. Interview Questions

1. Why would you use `display: grid` for `.hero-container` instead of `display: flex`?
   - Answer: `grid` lets you define explicit columns and gaps. It is ideal for two-axis layouts and makes the two-column hero layout easier to manage.
2. What does `clamp(2.5rem, 8vw, 4rem)` do?
   - Answer: It sets a fluid font size that never goes below 2.5rem or above 4rem, scaling with viewport width in between.
3. Why is `position: relative` used on `.hero-image`?
   - Answer: So absolutely positioned children like `.floating-icons` are positioned relative to it.
4. Why does `.profile-frame` use `overflow: hidden`?
   - Answer: To clip the image and glow inside the circular frame.
5. What is the purpose of `transform: translateY(-50%)`?
   - Answer: To center an element vertically when using `top: 50%`.
6. Explain the difference between `position: absolute` and `position: static`.
   - Answer: `absolute` removes the element from normal flow and positions it relative to the nearest positioned ancestor; `static` is the default flow.
7. Why use `@media (max-width: 768px)`?
   - Answer: To apply layout changes for tablet and mobile screens under that width.
8. How does `.social-icon:hover` improve UX?
   - Answer: It gives visual feedback on hover, making the icon feel interactive.
9. What effect does `box-shadow` have on perception?
   - Answer: It creates depth, making elements appear elevated.
10. Why is `border-radius: 50%` used on `.profile-frame`?
    - Answer: To make the container circular.
11. What does `min-height: 100vh` guarantee?
    - Answer: The hero section fills the full vertical viewport at minimum.
12. Why is `display: inline-flex` useful for `.icon-box`?
    - Answer: It allows inline placement while using flex layout for centered content.
13. When should you hide desktop-specific styles on mobile?
    - Answer: Whenever the desktop layout would not work in a narrow view; mobile should simplify.
14. What does `animation: pulse 2s ease-in-out infinite` do?
    - Answer: It makes the glow fade in and out continuously.
15. Why might `@keyframes bounce` be removed?
    - Answer: Because it is unused, and unused CSS should be removed for maintainability.
